Goal-conditioned Cosmos Policy for autonomous photography

Cosmos-Predict2.5-2B backbone, frozen. Image latents (Timg = 4-frame video) + action latent + value latent in one diffusion sequence. Goal P* = V5 8-key shot profile, injected via zero-init prefix on a T5 anchor (ControlNet-style). EDM σ-parameterized loss, balanced-two-heads sampling. Hindsight-relabeled supervision from random Blender clips.

The latent sequence is exactly [image_clip (T_img=4 frames) | action latent | value latent] — T_total = 6. Backbone is frozen; the only learned parameters are the ShotProfileVectorConditioner (~33K: Linear(8 → K·1024) + scalar gate). Image latent uses the real Cosmos VAE; action/value latents are tiled / broadcast in-place (no learned encoders). Image-clip filler (frames 1..T-1 = st+1) is a v6 prototype shim; issue #17 swaps it for a true 4-frame trajectory window.

Stage 3 writes scores back to data.json (per-frame, per-pair, under render_records[i][j].scores). Training reads data/trajectories/<placement>/data.json via iter_windows. Hindsight relabel: P* ← profile(s_end); V = -d_geom is the camera-subject geometric distance in radians (weight-free product metric).

EDM training objective & inference (Karras sampler)

σ sampling (per sample, not per slot): 50% — log(σ) ~ N(-1.2, 1.2)  (EDM default) 25% — log(σ) ~ U[log 200, log 1e5]  (extreme high — eps-head supervised) 25% — σ ~ U[1e-5, 2.0]  (extreme low — x0-head supervised) single backbone, single loss, balanced-two-heads regularization Inference (Karras schedule, ρ = 7) (a) Direct policy pin clean s_t at frame 0; sample noise at action + value N steps with Karras σ_i = (σ_max^(1/ρ) + i/(N-1)·Δ)^ρ extract â_t from the action latent — one forward pass (b) Best-of-N planning N diffusion seeds → (â_i, ŝ_{t+1, i}, V̂_i) â* ← argmax_i V̂_i — same backbone scores & imagines no candidate-action MPC; no lookahead beyond one step
