The denoising sequence is (s, a, s′, v) — current state, action, next state, value. s is clean conditioning; (a, s′, v) are noised and predicted. Goal P* is NOT a latent frame — it enters via cross-attention, the same path Cosmos-Predict2 uses for text prompts. State (= image) goes through the learned Cosmos VAE; action and value go through parameter-free normalize + replicate.

Training data — hindsight relabeling at the dataset layer

Hindsight relabel: every random Blender transition becomes a goal-conditioned tuple by treating the achieved profile P̂ = profile(st+1) as the goal. Because P* ← P̂ here, the per-tuple value target collapses to 0 — Vt only carries signal across the batch under counterfactual / noisy-goal augmentation (perturb P* away from P̂).
