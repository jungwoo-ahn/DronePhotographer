Training data — hindsight relabeling at the dataset layer

Hindsight relabel: every random Blender transition becomes a goal-conditioned tuple by treating the achieved profile P̂ = profile(It+1) as the goal. Because P* ← P̂ here, the per-tuple value target collapses to 0 — Vt only carries signal across the batch under counterfactual / noisy-goal augmentation (perturb P* away from P̂).
