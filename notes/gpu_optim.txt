  지금 가장 큰 병목은 GPU 3장으로 이미지 1장씩 순차 렌더링하는
  구조야.

  현재 방식 vs 개선 방식

  현재: Blender 1개 프로세스 → GPU 3장이 1장의 이미지 타일을 나눠서
  렌더
  GPU 3: ██░░░░██░░░░██░░░░  (이미지 타일 일부)
  GPU 4: ██░░░░██░░░░██░░░░  (이미지 타일 일부)
  GPU 5: ██░░░░██░░░░██░░░░  (이미지 타일 일부)
          img1   img2   img3  → 순차적
  - GPU 간 데이터 전송 오버헤드 있음
  - 이미지 사이사이 CPU 작업(카메라 이동, 파일 저장) 동안 GPU 놀고
  있음

  개선: Blender 3개 프로세스 → GPU 1장씩, 동시에 3장 렌더
  GPU 3: ████████████████████  (img 0,3,6,9...)
  GPU 4: ████████████████████  (img 1,4,7,10...)
  GPU 5: ████████████████████  (img 2,5,8,11...)
  - 각 GPU가 독립적으로 100% 가동
  - 이론상 ~3배 빠름
